# ai-happy-01 entry: "The bubble"

A golden retriever puppy mid-leap, catching a soap bubble in its mouth, while
a young child laughs beside it in golden-hour sunlight. One specific, joyful
moment: the puppy's delighted pounce, the iridescent bubble, the child's
unfiltered laughter — warm, saturated, and clear even at small size.

- `entry.png` — the image (JPEG bytes, 1024×683, ~137 KiB)
- `main.ts` — Node 22, stdlib only: copies `entry.png` byte-for-byte to
  `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR` when set)

Run locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
